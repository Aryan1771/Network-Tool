Cryptographic Integrity Protocol (SHA-256)

To ensure strict digital forensic admissibility, all acquired network captures undergo automated cryptographic baseline generation immediately upon ingest.

  • Original files are duplicated into data/evidence/ with unique ID timestamps.
  • Files are flagged with OS read-only permissions (S_IREAD).
  • SHA-256 cryptographic digest is computed across 64 KB streaming blocks.
  • Recalculating checksums verifies that not a single bit has been altered.

Tamper Demonstration

The Test Tamper feature is a demonstration utility for cryptographic integrity checking:

  1. Injects a single byte modification into the stored evidence copy.
  2. Immediately executes an automated SHA-256 recalculation.
  3. Displays a prominent TAMPER DETECTED warning badge.
  4. Logs an immutable TAMPER_DETECTED entry into the Chain of Custody audit trail.
